Accuracy

Treat values as good to a few feet, not survey grade. The map works in WGS84; EPSG:2913 is on NAD83(HARN), and there is more than one accepted way to convert between them. This page uses a null transform (no datum shift), the same one Portland Maps' servers use, so its numbers match theirs. pyproj's default instead applies a Helmert shift that moves points about 4 ft here (3.6 ft east, 2.1 ft north), and QGIS may pick either one. Bigger errors come from the sources themselves: how well each year's aerial was georeferenced (the 1925 scans especially), and how carefully you click.
